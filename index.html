Streaming Ingest & Deterministic Audit

An in-RAM ffprobe audit on a 2MB head slice (with MOOV-atom fallback) verifies every source before a byte hits disk. Unsupported inputs — 10-bit, malformed — fail fast with a legible reason, never a retry storm.

Content-Addressed Chunk Ledger

Sources split into 4-second chunks under SHA256 content IDs in a Redis micro-state ledger. Differential healing makes every re-run incremental — only failed or missing chunks are ever re-dispatched.

VRAM-Invariant GPU Transcode

One NVDEC decode feeds three scale_cuda rungs into three h264_nvenc encodes — the full ABR ladder per chunk without frames ever touching system RAM. Concurrency is engineered to the measured NVENC session ceiling, not guessed.

Local HLS Origin & Secure Playback

Native manifest assembly emits standard HLS (master + variants, MPEG-TS segments) to a local static origin, played through a vendored Shaka console. Short-TTL HMAC-signed JWTs gate access — the same zero-trust pattern proven in Genesis, minus the CDN bill.

Edge Intelligence Roadmap

Specced and in flight: native FFmpeg scene-boundary detection into the ledger, SigLIP embeddings via ONNX Runtime (CUDA) into local sqlite-vec for sub-millisecond moment search, and TensorRT-driven in-VRAM 9:16 verticalization. C++-backed runtimes only — no framework bloat.

Genesis — The Cloud-Native Predecessor

Ouroboros Metal is a ground-up rebuild of a fully working cloud pipeline: Payload CMS ingestion → GCS with Eventarc/Cloud Run orchestration and atomic locks → AWS Elemental MediaConvert → S3/CloudFront behind a sub-millisecond JWT edge function. Building it end-to-end produced the thesis this project runs on — for this workload class, managed cloud transcoding trades determinism and cost for convenience you don't need.

The rebuild kept the good ideas — event-driven design, atomic locking, zero-trust tokens, telemetry hooks — and moved the physics on-die. The original architecture remains documented on the Diagrams page as engineering lineage.
